# 湯けむり旅

日本国内の温泉地とご当地旅を紹介するホームページ

## 構成
- 静的サイト（HTML / CSS / JS、ビルド不要）
- ホスティング: Cloudflare Pages
- 外部依存なし（Webフォント・解析ツール・CDN を使用していない）
- 生成AIを開発ツールとして利用している。

## ローカル確認
`index.html` をブラウザで開くだけで動作する。

## デプロイ
`main` ブランチへの push で Cloudflare Pages が自動デプロイする。
